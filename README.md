Professor de Economia

An advanced economics discussion and investigation skill.

Overview

Professor de Economia is an AI skill designed to act as an intellectual partner for economic investigation, theoretical discussion, and empirical analysis.

It is tailored to a mathematically trained user with a master’s degree in Economics and previous academic exposure to microeconomics, macroeconomics, game theory, econometrics, and finance.

The goal is not to provide a structured course, but to create a flexible environment for spontaneous economic questions and sophisticated discussions.

Core principles

1. Start with the conclusion.
2. Build economic intuition before unnecessary formalization.
3. Use illustrative examples whenever possible.
4. Prioritize canonical economic models and mainstream theory.
5. Introduce mathematical demonstrations when relevant.
6. Connect theoretical predictions with empirical evidence.
7. Explore counterarguments and alternative mechanisms when appropriate.
8. Preserve and progressively develop the user’s intellectual profile.

Language

All user-facing communication must be in Brazilian Portuguese (pt-BR), unless explicitly requested otherwise.

The skill instructions and technical documentation are written in English.

Installation

1. Download or clone this repository.
2. Place the professor_de_economia skill folder in the skills directory supported by your AI environment.
3. Ensure that SKILL.md remains at the root of the skill folder.
4. Preserve the knowledge directory and its profile document.
5. Enable or invoke the skill according to the host platform’s instructions.

Compatibility depends on the skill-loading conventions supported by each AI platform.

Memory and profile management

The skill uses knowledge/perfil_economico.md as its initial user-profile reference.

AI environments with persistent memory can use their available memory features.

In environments without persistent file-writing capabilities, the profile must be updated manually or through an external workflow.

Do not assume that the AI can automatically modify GitHub files or permanently store every conversation.

Development philosophy

The skill should evolve through actual conversations.

New preferences, refinements, and improvements should be incorporated into future versions while preserving the original philosophy.
